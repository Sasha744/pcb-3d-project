# Модуль індикації та керування (Altium Designer)

Проєкт розробки принципової електричної схеми, односторонньої друкованої плати та 3D-моделі корпусу в середовищі **Altium Designer**.

## Опис проєкту

Пристрій являє собою компактний електронний модуль із тактовою кнопкою, світлодіодною індикацією, RC-ланцюгом та зовнішнім 3-контактним інтерфейсом для підключення живлення, сигнальної лінії та спільного проводу (`GND`).

### Основні етапи реалізації
* **Схемотехніка :** розроблено принципову електричну схему, призначено посадкові місця для всіх елементів та виконано валідацію проєкту без помилок.
* **Трасування плати :** виконано оптимальне компонування компонентів без перетину зв'язків, контур плати обрізано під габарити модуля в режимі *Board Planning Mode*, усі провідники розведено на верхньому шарі.
* **Перевірка правил :** підтверджено відсутність нерозведених ланцюгів , коротких замикань та порушень зазорів.
* **3D-моделювання корпусу:** навколо друкованої плати на шарі `Mechanical 1` побудовано напівпрозорі стінки корпусу за допомогою інструмента *Extruded 3D Body* із технологічним вирізом під штирьовий роз'єм `P1` та перевіркою відсутності перетинів.

## Склад компонентів (BOM)

| Позиційне позначення | Тип компонента | Призначення у схемі |
| :--- | :--- | :--- |
| **R1** | Резистор | Струмообмежувальний резистор у ланцюзі світлодіода |
| **R2** | Резистор | Підтягувальний / узгоджувальний резистор у сигнальному ланцюзі |
| **C1** | Конденсатор | Фільтрація завад та придушення брязкоту контактів |
| **D1** | Світлодіод | Візуальна індикація роботи |
| **S1** | Кнопка (`HDR1X2`) | Комутація ланцюга керування |
| **P1** | Роз'єм `1×3` | Зовнішнє підключення (живлення, сигнал, земля) |
